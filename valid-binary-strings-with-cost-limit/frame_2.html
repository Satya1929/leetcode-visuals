STEP 2: BACKTRACKING STATE & PRUNING
State Definition

We maintain a recursive state: f(ind, cost, last)

  • ind: Current length of the string being formed
  • cost: Current sum of indices where '1' is placed
  • last: The last character appended (0 or 1)
// 1. Cost Pruning
if (cost > k) return;

// 2. Base Case: String complete
if (ind == n) { ans.push_back(cur); return; }

// 3. Consecutive '1's Constraint
if (last == 0) {
    cur.push_back('1');
    f(ind + 1, cost + ind, 1);
}
